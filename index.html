联动规则清单

① 预测集：需同时满足“备料类型=零散备料”+“需求类型=滚动预测”才显示，且为必选；其余组合隐藏。
② PR编号：需同时满足“备料类型=零散备料”+“需求类型=直接请购”才显示，值由流程审核后 EBS 反写；其余组合隐藏。
③ 是否在途冲减：仅“备料类型=BOM备料”时显示且必填；取值来自 EBS，按 EBS 显示“Y / N”，字段只读，不可人工填写或选择；“零散备料”时隐藏。
④ 明细表“是否按MPQ”：取自 EBS，按 EBS 显示“Y / N”，字段只读，不可人工选择；=Y 时 MPQ 列方从 EBS 取值，=N 时 MPQ 列置空不可取数。若 EBS 的 MPQ 为 0、空值或未维护，取数后系统统一自动调整为 1。
⑤ 客户全称：输入关键字检索并选中客户后，自动带出“客户编码·销售区域·销售经理”（销售区域允许手工调整）。客户全称 / 客户编码 / 销售区域 / 销售经理 / 销售订单 均为选填。
⑥ 明细表“是否购买现货”：需求类型=“直接请购”时为必填；需求类型为一般预测/滚动预测时为选填。
⑦ 流程主题：由系统合成“{申请人}创建的{策备类型}流程”，例：张三创建的客户策提流程；策备类型随来源类型取“客户策提 / 供应链策提”。
⑧ 拟备物料明细：字段集合随“备料类型”整体切换——“BOM备料”显示 10 个数据字段方案，“零散备料”显示 20 个数据字段方案（均另含序号与操作列），两套互斥不并存。
⑨ 布尔字段：是否为新客户 / 是否为新产品 / 是否为首样 为必填；是否已过TR5 仅在“备料类型=BOM备料”时显示且必填，“零散备料”时隐藏；人工选择字段统一用“是 / 否”，EBS 来源字段（是否在途冲减、是否按MPQ）按 EBS 显示“Y / N”。
⑩ 风险等级：来源类型=客户备料时，不在发起人表单显示——由“物料计划科”节点在独立节点页《风险核定页》中选定（低风险 / 中风险 / 高风险 三选一）。
⑪ 风险应对方案：来源类型=客户备料时，由“销售总监”节点在独立节点页《风险应对方案页》中填写多行文本；风险等级为中风险或高风险时必填，低风险时选填；并附选填的“风险应对方案附件”。风险等级在该页只读回显。
⑫ 明细行金额口径：明细行“未税单价”“币种”两列保留字段但默认隐藏（不删除，便于后续启用），“备料金额”统一为“备料金额（RMB）”。
⑬ 备料范围：来源类型=客户备料时显示且必填；来源类型=供应链备料时隐藏。
⑭ 模板下载：点击“模板下载”导出 Excel，包含两个工作表——“BOM备料导入模板”“零散备料导入模板”，分别对应两套明细字段方案；模板中的必填与来源口径与明细行字段一致。
